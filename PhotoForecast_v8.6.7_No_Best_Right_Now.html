Category Browser

Use this when you know the type of shoot you want, rather than the exact place. It uses each location's saved category/status from the Field System.

Add / Edit Location

Use this for places you discover later, or edit custom locations you have already added. Saved custom locations appear in the main Region / Tier / Location selectors and are included in PhotoForecast backups.

Tip: save the location first, then go to Overview / Notes / Comps and add its hero image, personal notes and composition cards as normal.

Custom Locations

Locations added inside the app. These are stored in your PhotoForecast backup.
